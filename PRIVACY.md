# Annex Privacy Policy

Last updated: November 5, 2026

## What we store
**About servers:** server ID, server name, the ID of the channel used for wars, game progress (rating, gold, upgrades, vassal relations, war history), and blocks and settings.

**About users who play:** Discord user ID, display name, points, number of wars, and daily streak.

Annex can't read normal messages. It only receives slash commands and button presses, and doesn't request privileged intents. It stores no email addresses, IP addresses or message content.

## What we show
Server names, server icons and game results are shown to other servers playing Annex, for example on the world map, in rankings and in the chronicle. The display names of the top players appear on result cards and on their server's page. Server icons are loaded from Discord when a map is drawn and aren't stored permanently.

## Why
We use this data only to run the game: scores, rankings, the map, and preventing abuse. The legal basis is providing the service you asked for and our legitimate interest in keeping the game fair. We don't sell the data or use it for advertising.

## Where and how long
Data is stored in a database on the operator's own computer, and Discord processes it as the platform. It's kept while the bot is in the server. When Annex leaves a server, the server is marked inactive and removed from rankings. Past chronicle entries may keep the server's name. Data can be deleted on request.

## Your rights
You can ask for access to your data, or for it to be corrected or deleted, and you may have the right to complain to a data protection authority. Open an issue in this repository to make a request, without posting private details there.

## Children
Annex follows Discord's minimum age. Anyone under that age may not use it.

## Changes
We update this page when anything changes.
